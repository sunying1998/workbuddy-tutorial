照着做

五步：执行 → 抽数回算 → 算清分歧 → 局部返工 → 补来源

  1. 分阶段执行，先检查后计算
    按《项目说明.md》§5 已经定好的口径分析练习数据。先检查重复记录、缺失评分和无法关联的场次，把这些问题单列；每个数字结论标明计算口径和来源文件。生成初稿后，先给我一张核对表。核对通过之前，不要制作最终报告。
  2. 自己抽两个数字回算（本讲最重要的动作）
    抽哪个怎么手算
    有效报名报名总行数 − 无法关联 − 重复提交 − 已取消
    总平均分只把填了评分的挑出来，先求和，再除以条数
  3. 口径有分歧的，在本讲算清楚差多少
    这两条口径的结果差多少？请按【口径 A】和【口径 B】各算一次，把两个结果并列给我，并说明各自的依据。
  4. 对不上就局部返工，不要让它重做全部
    第【N】个数字不对。我按【口径】算出来是【你的结果】，你按【你理解的口径】算的是【它的结果】。请只重算这一项并说明口径，其他部分不要动。
    官方在对话区提供了停止入口：任务执行中输入框区域会显示停止入口，可随时中断，中断后可在同一任务里继续追问 —— 这就是"局部返工"该用的方式，不要重开任务。
  5. 核对表每条都要有四列
    数字 / 结果 / 口径 / 来源（文件 + 纳入及排除的记录编号）。核对通过即本讲结束。
中途检查

五条，一条都不能放

  1. 每个数字都有来源
    缺来源 = 不接受。
  2. 数据问题单列
    没有混进结论段。
  3. 你至少复算出 2 个数字
    没复算 = 没核验。
  4. 反复同一个错误 → 用"局部返工"指令
    不要重开任务，不要让 AI 重做全部。
  5. 本讲不产出最终报告
    初稿 + 核对表通过后，才进第 5 讲做最终交付物。
三类记录的处理要在报告里看得见：①须剔除的已剔除；②缺评分的只剔出均分、文字保留；③须解释的被解释。

常见失败

四类错误，配好纠正指令

现象原因可复制的纠正指令
到场率算错分母用了报名总行数，没剔除无效与取消到场率的分母是"有效报名记录数"：报名总行数减去无法关联、重复提交、已取消。请按这个口径重算到场率，其他数字不动。
平均分被拉低把评分缺失当 0 分评分缺失的那条不计入平均分，但它的文字反馈要保留并单独说明。请重算平均分，并列出你用了多少条评分。
数字对但来源对不上没做追溯请给核对表每个数字补上"纳入及排除的记录编号"，没有编号的数字不算通过。
报告只有结论没有口径结果导向每个结论后面补口径和来源文件，再发一次。

必须完成
照着做

五步：看目标 → 写四行 → 补验收 → 让它复述 → 改一遍

  1. 先看"完成的样子"
    回首页查看「最终交付长什么样」，问自己三句话：这份东西给谁看？他看完要能回答哪几个问题？凭什么说他能信这些数字？
  2. 按官方建议补充的四项信息，写下前四行
    官方在创建任务时推荐优先补充：目标是什么 / 输入是什么 / 输出格式 / 约束条件。
  3. 补上第五行「验收办法」
    官方四项告诉 AI"做什么"，验收才告诉它"做到什么算对"。这一行写不出可操作的话，任务就还没定清楚。
    验收必须覆盖三类记录：须剔除的 / 缺评分但保留文字的 / 须解释的——缺一类不算通过。
  4. 把任务卡发给它，只让它复述，不让它干活
    这是我这个任务的任务卡：【贴你的任务卡】。请你用你自己的话复述一遍：目标、输入、输出格式、约束、验收各是什么；并指出其中哪一条最含糊、你希望我补充什么。现在不要开始做事。
  5. 按它的提问改一遍，存成 我的任务卡.md
    执行方式（先规划再执行）留到第 2 讲，本讲到此为止。

【任务卡】城市阅读节 · 活动复盘
目标：产出一份能交给主办方复盘会使用的活动复盘报告，以及一页展示材料。
输入：《项目说明.md》《场次安排.csv》《报名记录.csv》《反馈记录.csv》（四份文件在同一文件夹）
输出格式：
  ①复盘报告（五段：活动概览与数据范围 / 报名与到场 / 各场次表现 / 观众反馈 / 问题与改进建议）
  ②一页展示材料（1 个核心数字 + 1 张图 + 1 条建议）
  ③来源与结论核对表（数字 / 结果 / 口径 / 来源：文件 + 纳入及排除的记录编号）
约束：
  - 只使用上述四份文件，不使用任何外部或真实资料
  - 计数单位用「条 / 人次」，不用「人」
  - 评分只说明平均分高低，不写"最受欢迎"
  - 每个数字都要标口径与来源
验收：
  - 抽 2 个关键数字（有效报名、总平均分）必须能被人复算出来
  - 三类记录都要正确处理，缺一类不算通过：
      ①须剔除的（无法关联场次、重复提交）已剔除；
      ②缺评分的只剔出平均分计算，文字反馈保留并用于定性分析；
      ③须解释的（取消报名、高分反馈中的改进意见）在报告里被解释，而不是当成数据错误
    ＊只"找出一处问题"不算通过——那是第 7 讲独立挑战的最低达标线
  - 图表数字与正文数字完全一致
  - 每个数字都标了口径与"纳入及排除的记录编号"

讲师提示：这张卡与《项目说明.md》的要求一一对应。学员写不出的地方，正是他没读到的部分； 验收里只写"指出一处问题"的，多半只看了数据提示的标题。

常见失败

四个坑 + 可复制的纠正指令

现象原因可复制的纠正指令
目标写成"分析数据"把动作当目标目标要写"产出什么给别人用"。请改成：产出一份【给谁看】的【什么东西】，他要能回答【哪几个问题】。
输出格式只写"报告"没说结构请把输出格式写细：报告分几段、每段写什么；是否另有一页材料。
约束里没有红线漏了信息安全请补一条硬约束：只使用我提供的四份文件，不上传、不引用任何真实资料。
验收只写"指出一处问题"没读完三类要求验收必须覆盖三类记录：①须剔除的已剔除 ②缺评分的只剔出均分、文字保留 ③须解释的被解释。只写"找出一个问题"不算通过。
写完卡就让它开始做越到第 2 讲的内容本讲只交任务卡。执行方式（先规划再执行）在第 2 讲。
独立练习

只改一个条件

交付对象从「主办方复盘会」换成 「下一届的筹备组」。 重写任务卡的目标、输出格式、验收三行（输入与约束不变），并说明为什么这三行必须改。

展开参考答案（做完再看）
  1. 目标变了：复盘会是"我们做过什么、结果如何"；筹备组要的是"下一届怎么改"——目标从"总结"变成"给出可执行的改进项"；
  2. 输出格式变了：需要"改进清单"（问题 → 原因 → 建议动作 → 依据的数字），而不只是五段式报告；
  3. 验收变了：筹备组的验收是"每条建议都有数据依据、且能落到具体动作"；
  4. 不变的部分：输入文件、计数单位、只用虚构数据这些约束一个字都不用改 —— 这正是任务卡的价值：改条件时只改该改的那几行。

第 5 讲 · 给每一步配手段

自动化不是程序员的事,下面这些办法,大部分都不用你写代码。

本讲目标

知道每一步有什么自动化办法,查表即用。先破一个误区:自动化不是程序员的事。

5.1 手段分层总览(门槛从低到高)

层级方式要不要写代码适合场景
第 0 层直接把活交给 AI不用一切(首选)
第 1 层WPS/Excel 内置功能不用套公式、汇总、对比
第 2 层无代码平台(空间数据表、钉钉/飞书自动化、RPA)基本不用跨系统重复操作
第 3 层让 AI 封装成脚本/模板,双击复用不用(自己)固定流程完全自动
第 4 层爬虫 / Python 脚本要,但由 AI 代劳复杂定制
记住一条

你只管说需求,写代码的事交给 AI。第 0 层就是为此准备的。

5.2 第 0 层:直接把活交给 AI(最推荐,零门槛)

你不懂 Python 没关系——AI 就是那个"懂 Python 的人"。你只要用第 3 讲的方法把需求说清楚,AI 帮你写脚本、处理表格、生成结果。

可复制提示词

我不会写代码。我想【做什么事】,平时我是【手动怎么做的】。请帮我直接做好 / 写一个能自动完成的脚本,并告诉我以后怎么用。

5.3 第 1 层:WPS/Excel 内置功能(零门槛)

不装任何新东西,表格软件自带的就能解决一大半:

  • 函数/公式:VLOOKUP、SUMIF、条件格式等,套一次下次复用
  • 数据透视表:快速汇总、对比
  • 宏录制:点"录制",把你手动操作录下来,以后一键重放(WPS/Excel 都支持)

5.4 第 2 层:无代码平台(基本不用写代码)

跨系统、跨软件的重复操作,用现成的自动化工具:

  • 空间数据表(重点):把 Excel 导入空间的"数据表",变成可筛选、可查询的库,还能直接生成看板——这是汇总分析最省事的一条路(见第 2 讲、第 6 讲)
  • 钉钉/飞书/企微的机器人 + 定时:定时发通知、推送告警
  • RPA 工具(如影刀、UiBot、Power Automate 桌面版):用"录制"方式把你的鼠标键盘操作录下来自动重放,适合"每天打开网页→下载→保存"这类活
  • 多维表格自动化(飞书/钉钉/WPS):设好规则,数据一变自动触发计算、通知

5.5 第 3 层:让 AI 封装,一次做好反复用(固定流程首选)

有固定流程想完全自动?让 AI 帮你做一次,以后你只负责"双击"或"粘贴":

  • 封装成脚本:AI 写好脚本后,你双击 .bat 文件就跑完
  • 封装成模板:AI 做好带公式的模板,你每次把新数据贴进去,结果自动出

5.6 第 4 层:爬虫 / Python 脚本(复杂定制,交给 AI)

你提到的"爬虫""操控电脑下载"属于这一层,门槛最高——但你不用自己学。把需求提给 AI,它写代码、你验证结果。你只需会说"要抓什么数据、从哪个网站、存到哪"。

5.7 回到三步工作,不懂代码怎么选

以"自动生成数据判断"为例,不懂代码的同事可以这样选:

步骤不懂代码怎么选
下载数据第 0 层让 AI 写定时下载脚本 / 第 2 层用 RPA 录制下载
套公式第 1 层模板覆盖 / 空间数据表导入后筛选查询
汇总第 0 层让 AI 汇总分析 / 空间数据表 + 看板

本讲小结

  • 手段分 5 层,门槛从低到高,前 3 层不用写代码
  • 核心心法:你不懂代码没关系,AI 懂;你负责说清楚,它负责干
  • 优先用第 0~2 层,复杂需求交给 AI(第 4 层)

## 📖 这是什么

你在日常工作中一定有这些场景：

> 每月要把几十张采购表翻一遍找异常数据 · 每周要把 Excel 汇总成汇报 PPT · 每天要在几个系统之间复制粘贴同一批字段 · 想知道哪个商品成本涨了，得肉眼比对半天

这套教程不讲原理、不讲算法，只回答一个问题：

**手上的重复活，怎么一条条交给 AI 干掉？**

7 讲全部围绕一个闭环展开 —— **拆解工作 → 配手段 → 让它自动跑**。

## 💡 核心心法

> [!TIP]
> **重复的活交给 AI，判断的活留给自己。**
> 你不懂代码没关系 —— AI 就是那个懂代码的人。

这套方法论的核心不是「学会用 AI」，而是学会把工作**拆成 AI 能接得住的形状**。

```
你的业务需求
      ↓
  ① 拆成步骤链        ← 第 4 讲
      ↓
  ② 每步配手段        ← 第 5 讲
      ↓
  ③ 封装复用 / 定时跑  ← 第 5 讲
      ↓
  ④ 结果变成汇报      ← 第 6 讲
```

## 🛠️ 自动化手段的 5 个层级

摘自 [第 5 讲](https://sunying1998.github.io/workbuddy-tutorial/lesson5.html)，门槛由低到高：

| 层级 | 方式 | 要写代码吗 | 适合场景 |
| :---: | :--- | :---: | :--- |
| **0** | 直接把活交给 AI | 不用 | 一切（**首选**） |
| **1** | WPS / Excel 内置功能 | 不用 | 套公式、汇总、对比 |
| **2** | 无代码平台（数据表、钉钉/飞书自动化、RPA） | 基本不用 | 跨系统重复操作 |
| **3** | 让 AI 封装成脚本 / 模板，双击复用 | 不用（自己） | 固定流程完全自动 |
| **4** | 爬虫 / Python 脚本 | 要，但由 AI 代劳 | 复杂定制 |

> [!NOTE]
> 优先用第 0 ~ 2 层。真正需要第 4 层时也不用自己去学 —— 把需求丢给 AI，它写代码，你验证结果。

## 🚀 试一个最小的例子

不用学完 7 讲，现在就能用。把下面这段直接丢给 AI：

```text
我是采购，这是我的采购成本表（见附件）。
帮我找出采购单价环比上涨超过 10% 的商品，
输出成一张表，包含：商品名、上月单价、本月单价、涨幅。
```

**你会发现门槛不在技术，而在于要把话说清楚** —— 这正是第 3 讲要解决的问题。

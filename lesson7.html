照着做 ①

抽模板：文件名要是变量，不是写死的

把 6 讲里每次都要说同样的话的部分抽出来。注意：文件名写成变量 + 字段要求，否则换一组数据就用不了。

【任务模板】活动复盘（通用） 角色：我是【岗位】，手上是【活动名称】的数据。 输入（文件名是变量，结构与字段要求固定）： ① 项目说明：【说明文件名】——需含交付要求、时间范围、口径约定、验收标准 ② 场次表：【场次表文件名】——字段需含 场次编号 / 主题 / 日期 / 计划名额 ③ 报名记录：【报名记录文件名】——字段需含 记录编号 / 场次编号 / 报名人 / 报名时间 / 报名状态 ④ 反馈记录：【反馈记录文件名】——字段需含 反馈编号 / 场次编号 / 评分 / 文字反馈 说明：若字段名不同，先告诉我差异，不要自行猜字段含义 口径：有效报名 = 可关联 ∩ 非重复 ∩ 非取消；单位是条/人次； 平均分只算填了评分的；已取消与高分改进意见不算数据错误 要求：①开「计划」模式先给方案，我确认后再执行 ②检查重复/缺失/无法关联并单列 ③每个数字标口径 + 来源文件 + 纳入及排除的记录编号 交付：①复盘报告（五段结构）②一页展示材料 ③来源与结论核对表 验收：抽 2 个数字能复算出来且必须与本组数据的正确答案一致；图表与正文数字一致
照着做 ②

自动化草案：必须留人工把关点

先用三条标准筛：重复发生、规则明确、不需要判断。然后写草案 —— 本讲只是草案，不要求真的建起来。

要素内容
触发（期望规则）例如："活动结束后第 3 个工作日"。这是你希望实现的规则，不是照抄官方示例 —— 官方明确的定时规则是"每周多天"（如每周一、三、五 09:00）和"每月多天"（如每月 1 日、15 日、28 日 09:00），官方示例里没有"每月最后一个工作日"这种写法，能不能这么设，要在客户端里试过再写进正式方案
输入数据文件放哪里、什么格式、字段要求
动作检查 → 计算 → 生成核对表
输出核对表先给人看，不直接对外发
人工把关点数字异常、口径变化、对外发送前
出错了怎么办停在哪一步、谁收到通知、怎么回滚
官方安全提醒：任务在无人值守下自动执行，涉及文件写入 / 删除 / 资金操作的提示词要审慎；官方建议先低频率试运行，并对涉及改动与对外发送的部分保留可追溯日志。
中途检查与预期结果

四条检查 + 达标线

检查项通过标准
模板能不能复用口径与验收标准固定，文件名是变量 + 字段要求（写死文件名的模板换数据就用不了）
自动化有没有把关点必须有一段"人工把关点"，没有就是设计缺陷
触发规则是否越界超出官方示例（每周多天 / 每月多天指定日期）的，要标为"期望规则、待客户端验证"
独立挑战有没有看答案过程中不看，卡住了记下来，做完再对照

适合 vs 不适合自动化

适合自动化

数据检查（重复 / 缺失 / 无法关联）、按场次汇总、生成核对表初稿。

不适合自动化

确认口径变了没有、判断"这个结论能不能对外说"、异常时的取舍、对外发送。

判断口诀：重复且规则明确的交给机器；需要判断和对外承诺的留给自己。
达标线（收紧版）：允许中途算错并自行修正，也鼓励把卡点记录下来；但最终验收时，"指出至少一处数据问题"和"至少两个关键数字复算正确"这两项必须做到。卡点记录有价值，但不能代替正确结论。
常见失败

四个坑 + 纠正指令

现象原因可复制的纠正指令
模板里还留着一次性的内容把整段对话直接当模板请把模板里只属于这一次的内容（具体数字、临时要求）删掉，只保留每次都一样的部分，变量位置用【】标出。
自动化草案没人把关把"全自动"当目标请给草案补上"人工把关点"：哪些情况下必须停下来让我确认？什么情况下不能自动对外发？
独立挑战时忍不住看答案依赖参考答案先做完再对照。卡住的地方先记下来，做完后我们一起看卡在哪一步。
换数据后结论直接照搬没重新跑口径新数据要重新做数据检查。请先列出这次发现的问题，再给数字。
独立练习（综合挑战）

完整走一遍

用第二组数据（悦读周），从「先规划」到「最终报告 + 一页展示材料 + 核对表」，全程不看答案。 提交：①任务计划 ②数据检查结果 ③报告与一页材料 ④来源与结论核对表 ⑤独立完成记录（总时长、卡住的步骤、返工次数、下次要改的地方）。

展开验收要点（做完再看）
  1. 能指出至少一处数据问题（重复 / 缺失 / 无法关联）；
  2. 至少两个关键数字必须复算正确（建议抽"有效报名记录数"和"总平均分"）；
  3. 图表与正文数字一致；
  4. 口径与模板一致，没有因为换了数据就改口径；
  5. 交付物齐全且命名规范。

允许中途算错，也要求自行修正（修正过程写进独立完成记录）；但最终提交时第 1、2 项必须正确 —— 卡点记录有价值，但不能代替正确结论。

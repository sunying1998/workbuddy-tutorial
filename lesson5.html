照着做

五步：定结构 → 做一页 → 补证据 → 定命名 → 验收

  1. 把初稿升级为最终报告，先定结构（五段）
    请把初稿整理成最终报告，结构固定为五段：①活动概览与数据范围 ②报名与到场 ③各场次表现 ④观众反馈 ⑤问题与改进建议。每段里的每个数字后面都要跟"口径 + 来源文件 + 纳入及排除的记录编号"。先给我目录，我确认结构后再展开。
  2. 做一页展示材料：限制在一页、三个要素
    基于最终报告做一份一页展示材料（网页或文档，不限格式）。只要三样东西：一个核心数字、一张最能说明问题的图、一条最该改的建议。每个要素都要标它的来源。
  3. 给图表补证据 —— 选图原则
    要说的意思合适的图
    各场次报名多少条形图（按数量排序）
    报名与到场差多少同一张条形图里两列并列，不要拆成两张
    评分高低条形图带数值标签；样本只有 2–3 条时，同时标出条数
  4. 定文件命名，别覆盖旧版
    城市阅读节复盘报告_v1_2026-09-22.md 城市阅读节一页展示_v1_2026-09-22.png
    格式不限（.md / .html / .docx / .png 都行），但文件名要带版本与日期。
  5. 验收产物（右侧边栏）
    官方右侧边栏四个功能区：产物 / 工作空间文件 / 变更 / 浏览器；产物右键可以"打开文件夹"。检查四件事：
    ①数字与核对表一致 ②每张图有来源标注 ③文件名带版本与日期 ④一页材料单独打开也能看懂
预期结果

报告与一页材料

学员可见：报告五段结构完整，每段数字带"口径 + 来源"；一页材料含 1 个核心数字 + 1 张图 + 1 条建议，各自带来源。

最该写进"建议"的一条：有一条评分 5 的反馈同时提到座位不够、有人站着听完 → 建议下一届按报名名额配置座位，并把"评分高"与"体验有硬伤"分开看。

不能这么说：不要写某场"最受欢迎"。正确表述是"平均评分最高（5.00），但只有 2 条评分"——样本太小，不足以支撑"受欢迎"的判断。 任何"最好 / 最差 / 最受欢迎"的表述，都要么附上条数，要么改成"平均分最高 / 最低"。

常见失败

五个坑 + 纠正指令

现象原因可复制的纠正指令
图表数字和正文对不上图表单独生成，没回查请核对每一张图的数据与报告正文数字是否一致，不一致的以核对表为准，逐张修正并把不一致处列出来。
一页材料出现报告里没有的数字临时另算一页材料上的所有数字必须来自最终报告。请列出每个数字在报告中的位置，报告里没有的删掉或补进报告。
只有结论，没有口径和来源结果导向每个结论后面补"口径 + 来源文件 + 纳入及排除的记录编号"，再发一次。
用"最受欢迎"下结论拿小样本当结论评分只能说明平均分高低。请改成"平均评分最高 / 最低"，并写明该场有几条评分。
文件名混乱或覆盖旧版没定命名规则文件名统一为「项目名_内容_v版本_日期」，同一版本不要覆盖，改了就升版本号。
独立练习

只改一个条件

交付对象从「主办方复盘会」换成 「给财务看的一页材料」。 从现有数字里选两个放上去，并说明：①为什么选这两个；②这份材料还缺什么才能支撑投入产出判断。

展开参考答案（做完再看）
  1. 现有数据只能做"规模初筛"：可用的是「有效报名 27 条（27 人次）」「报名名额填充率 58.7%」。注意这两项说的是报名规模：填充率只是有效报名记录数 ÷ 计划名额合计，反映"报名相对计划名额的比例"，不代表实际座位使用（到场是另一回事，练习包里也没有实际座位数）；
  2. 不能做投入产出判断：练习包里没有任何成本数据——没有场地费、物料、人力、单场成本，也没有收入或预算。所以"值不值得办"这类结论在这份资料上无法得出；
  3. 合格答案要明确写出缺什么：单场成本（场地 / 物料 / 人力）、预算与实际支出、是否有赞助或收费；
  4. 「总平均分」「场次评分排名」与财务的判断目标关联弱，可以砍掉；若保留「到场率 77.8%」，必须说明分母是有效报名记录数；
  5. 关键判断：同一份数据面向不同对象，选的是不同的数字组合；同时要能说清"目前只能做到哪一步、下一步需要什么资料"。

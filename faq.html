卡点 1–3

计划、文件、数字

现象检查下一步
计划写得漂亮，但它根本执行不了 计划里有没有：每一步用哪个文件、字段怎么关联、验收办法 回到第 2 讲的自检表补全，然后用「调整计划」让它重出一版；不要点「开始执行」
多个文件的结论互相冲突 两个结论是不是各自基于不同口径 / 不同记录范围 回第 3 讲：先确认关联字段与口径，把"纳入及排除的记录编号"写进核对表，冲突往往当场消失
数字不对 分母是什么？无效记录剔了吗？缺评分有没有当 0 分？ 用第 4 讲的局部返工指令：指出你按什么口径算出多少，只让它重算这一项

卡点 4–6

技能、自动化、概念混淆

现象检查下一步
Skill 装了却没生效 技能开关是否打开？有没有用它的触发方式说话？ 官方说明：关闭 ≠ 卸载；关闭后不会参与模型自动调用。先确认已启用，再问它"我说什么话会触发你"，拿 3 个例句回来试
自动化跑完，结果质量反而下降 无人值守时它按什么口径算的？改动是否有日志？ 回第 7 讲：给草案补人工把关点，把口径写进提示词，先低频率试运行，并保留可追溯日志
资料库和任务工作空间分不清 你要的是"文件放哪"还是"任务清单怎么分组" 选择工作空间 = 指定本地目录（任务在哪读写）；资料库 = 产物存放与协作（左侧边栏进入，含"我的文档 / 团队空间"）；任务列表里的空间 = 按工作空间分组的任务

安全与边界

几条官方红线

主题官方说明
数据怎么处理 任务对话：原始任务文件默认在本地处理；完成任务所需的数据片段会送到服务端，服务端用后即弃，不保存、不用于模型训练
资料库：上传到资料库的办公与本地文件（PDF / Word / PPT / Excel、图片、音视频）由腾讯网盘提供存储服务；在 WorkBuddy 中创建的 MD / CSV / HTML 内容存储在 WorkBuddy 云端。也就是说：放进资料库 = 上云，与"任务在本地处理"不是一回事
授权范围只能访问你主动勾选授权的文件夹；系统敏感目录自动拦截，高危操作需二次确认
默认权限会拦什么四类会停下来要你确认：写入受保护或敏感路径 / 删除受保护文件或批量删除 / 执行脚本、命令或外部程序 / 网络访问或敏感能力
完全访问权限是全局开关（当前客户端所有任务统一生效），且不跨设备。官方建议"完全放开用完即关"，只在可恢复、可隔离的任务里短时间使用
处理重要资料官方提示：先为任务新建独立文件夹、只放副本；默认权限可以减少误操作风险，但不能替代备份
批量删除与备份删除保护优先移入回收站；批量删除审批默认 50 个；自动备份默认开启（改已有文件前生成快照）
本站所有示例数据、机构、活动、姓名全部为虚构；课程不展示、也不要求你上传任何公司数据。

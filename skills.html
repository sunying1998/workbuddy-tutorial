优质 Skills

这里只放实际用过、确认好用的 Skills——用过一个加一个，不堆没验证过的。

Skills 是什么

如果说「提示词」是你每次跟 AI 说的话，那Skills 就是把一套成熟做法打包好的能力——装上一次，之后遇到同类活儿直接调用，不用每次重新解释一遍。

打个比方：提示词像是每次口头交代，Skills 像是写成标准作业手册。

已验证好用的

Skill · 实测好用
Archify
一句话生成流程图、架构图、时序图、数据流转图、状态图，输出可交互的 HTML（支持深浅色、可导出 PNG / SVG）。画采购流程、审批流程、数据流转关系很好用。

怎么用

  1. 点上面的名称，进 GitHub 看说明和示例；
  2. 确认适合自己的场景后安装；
  3. 装上后，直接跟 AI 说要做什么图／什么事，它会自动调用对应技能。

第 7 讲 · 实战串讲

把前 6 讲串成完整流程,用真实业务走一遍。

本讲目标

掌握完整套路:拆解 → 配手段 → 沟通 → 延展 → 沉淀空间 → 闭环。

7.1 案例 A 全流程:自动生成数据判断

  1. 拆解:下载数据 → 套公式判断 → 汇总
  2. 配手段:定时下载 + 空间数据表/WPS预置公式 + AI 汇总分析
  3. 沟通:每一步用第 3 讲的话术跟 AI 说清楚
  4. 沉淀空间:结果表存进空间数据表
  5. 延展:数据表 → 生成看板 → 分享给领导

7.2 案例 B 全流程:成本异常告警 + 催办闭环

  1. 拆解:识别异常商品 → 通知采购员 → 跟进确认
  2. 配手段:AI 定时分析异常 + 钉钉机器人推送 + 自动 @ 采购员催办
  3. 沟通:把"识别规则、通知对象、催办节奏"跟 AI 说清楚
  4. 沉淀空间:异常记录、处理状态存进空间,团队可查
  5. 闭环:直到采购员回复确认才停止催办

7.3 进阶方向

学完基础后,可以继续探索:

  • 多步骤自动化串成一条流水线
  • 定时任务自动跑
  • 把常用流程沉淀成空间模板,供团队复用
